- **翻轉是唯一沒有明顯副作用的擴增**：mAP50-95 +0.032（略超出雜訊，且是全部擴增中唯一提升者）、dynamic_obstacle recall 0.495 → 0.609。與人行道左右大致對稱有關，換場景未必成立。
- **大角度使 dynamic_obstacle 變好**（AP50 +0.069、recall 0.593），但 person 同時變差，兩者互相抵銷，整體 mAP50 看不出差異。

- **限制**：單一 seed，差距在約 0.03 內不下結論；dynamic_obstacle 的 test 僅 91 個實例；三組各只改一個因素，無法排除因素之間的交互作用，而 run05 的結果正顯示交互作用可能存在。

**結論**

- **雜訊比先前假設的大**：run04 的 test mAP50 標準差 0.034、person AP50 0.033、dynamic_obstacle AP50 0.041，最大與最小相差 0.07 左右。先前採用的 ±0.03 約只是 1 個標準差。best epoch 也隨 seed 在 15～42 間大幅變動。

- **大角度與 run05 的 person 下降仍超出雜訊**：run11 的 person AP50 0.736 約比 run04 平均低 2.2 個標準差（僅單一 seed，屬暫定）；run05 的 0.588 低於 run04 平均約 7 個標準差，明確超出雜訊。
- **選模型**：valid 的標準差較小（mAP50 0.007～0.013），但 test 與 valid 的排序並不一致，仍需搭配多個指標。
- **限制**：n=3，標準差本身估計不穩；只有 run04、run09 有多個 seed，其餘 run 仍為單一 seed；test 的 dynamic_obstacle 僅 91 個實例。

### 4.3 輸入尺寸比較（imgsz=320 vs 416，run09 設定）

**test 指標（平均 ± 標準差，n=3）**

**結論**

- **imgsz=416 沒有改善**：mAP50、dynamic_obstacle AP50 與 recall 的平均差都小於 1 個標準差，三個 seed 的配對差正負不一，無法辨識效果。

- 本機推論速度：imgsz=416 約 1.7～1.8 ms／張，與 320 相近（約 1.6～1.7 ms），在 Mac M4 Pro 上沒有可辨識的差異；此數字不代表 Jetson Nano，部署與 FPS 實測暫不進行。
- valid 的標準差在 416 變大（mAP50 0.053 對 0.013），模型選擇更不穩定。
