## 更換實驗設計重跑時的檢查清單

1. 因子是否改變（資料版本、抽樣比例、正則化、旋轉範圍）？→ 重算實驗組合數量。
2. 類別是否改變？→ 重新檢視標註規則（D1–D6）與 test 集內各類別數量。
3. test 集是否仍適用？→ 現有 test 為同一路線與兩套服裝；若新增資料或補拍，需重新定義區塊。
4. 輸入解析度是否改變（320／416／640）？→ 重新判斷護腕可見度（D5）與最小框尺寸（D6）。
5. HSV 分析用途是否改變？→ 重新確認 B5。
6. 驗收指標是否改變？→ 同步更新評估指標與 Nano 部署目標（≥15 FPS）。
